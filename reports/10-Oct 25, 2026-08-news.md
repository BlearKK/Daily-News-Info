<ul>
<li><strong>摘要</strong>：一项针对 Claude Code、OpenCode 和 mini-SWE-agent 等 Coding Agent 外围框架（Harness）的受控研究显示，切换不同复杂度的框架对任务通过率的提升极为有限，但单次任务成本却可能暴增高达 3 倍。</li>
<li><strong>要点</strong>：</li>
<li>成本增加的主要原因是每轮 Agent 交互中重复发送了体积膨胀的 System Prompt。</li>
<li>框架结构的复杂化并不必然带来系统问题解决能力的质变。</li>
<li>建议开发者与产品团队优先优化底层 Prompt 与模型能力，避免盲目堆叠 Harness 复杂度。</li>
