<ul>
<li><strong>摘要</strong>：OpenAI Codex 开发者 Eric Provencher 警告，盲目使用多个并行子 Agent 会因相互不信任和重复验证导致“协调税”，导致 Token 成本暴涨而无实质质量收益。</li>
<li><strong>要点</strong>：</li>
<li>实例显示 1,393 个 Agent 在单次重构中消耗了 2 万美元 Token，效果不如单个精细模型</li>
<li>Agent 间缺乏信任会导致严重的重复检查与计算资源浪费</li>
<li>建议开发者优化单个 Agent 的逻辑深度而非盲目扩展 Agent 数量</li>
<li><strong>标签</strong>：#AI #Agents #OpenAI #DevOps</li>
<li><strong>来源与时间</strong>：The Decoder · 13 小时前</li>
</ul>
