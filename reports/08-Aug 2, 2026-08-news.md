<h3 id="mcp20httpssimonwillisonnet2026jul31statelessmcp"><a href="https://simonwillison.net/2026/Jul/31/stateless-mcp/">无状态 MCP 2.0 规范正式发布：大幅简化客户端与服务端实现</a></h3>
<p>模型上下文协议（Model Context Protocol）发布 2.0 版（2026-07-28 规范），由传统“有状态双请求”模式简化为“无状态单请求”模式，极大降低了开发与扩展门槛。</p>
<ul>
<li><strong>要点</strong>：</li>
<li><strong>极简架构</strong>：消除了服务器端维护 Session ID 的需要，单次 HTTP 请求即可完成工具调用，更易于构建高并发、水平扩展的 Web 接口。</li>
<li><strong>生态爆发</strong>：社区迅速涌现了命令行探测工具 <code>mcp-explorer</code>、数据库集成 <code>datasette-mcp</code> 及 LLM 客户端集成工具。</li>
<li><strong>安全考量</strong>：相比于给予 Agent 完整的 Shell/Curl 权限，MCP 提供了更易审计和控制的沙箱环境，有效防御提示词注入攻击。</li>
<li><strong>标签</strong>：#MCP #Anthropic #开源工具 #AI安全</li>
<li><strong>来源与时间</strong>：Simon Willison · 1 天前  </li>
<li><strong>延伸来源</strong>：<a href="https://simonwillison.net/2026/Aug/1/datasette-apps/">datasette-apps 0.2a0</a>, <a href="https://simonwillison.net/2026/Jul/31/llm-mcp-client/">llm-mcp-client 0.1a0</a></li>
</ul>
<h3 id="copilotwordhttpsthedecodercomasecurityresearcherbuiltaselfspreadingwormthathidesinsideworddocsandhijacksmicrosoftcopilot"><a href="https://the-decoder.com/a-security-researcher-built-a-self-spreading-worm-that-hides-inside-word-docs-and-hijacks-microsoft-copilot/">微软 Copilot Word 插件遭遇“自传播蠕虫”漏洞</a></h3>
<p>安全研究员成功演示了一种针对 Word 版 Microsoft Copilot 的蠕虫式攻击：隐藏在文档中的隐形提示词注入（Prompt Injection）会在文档复用时自动扩散至新文件。</p>
<ul>
<li><strong>要点</strong>：</li>
<li><strong>漏洞机理</strong>：利用 Copilot 读取文档上下文的特性，将恶意指令在用户不知情的情况下注入到新生成的文件中，实现自动繁衍。</li>
<li><strong>修复迟缓</strong>：微软已确认该漏洞的存在，但历经 144 天和两次修复尝试，目前仍未能完全解决该问题，暴露出 AI 助手在集成办公软件时的核心安全短板。</li>
<li><strong>标签</strong>：#网络安全 #Microsoft #Copilot #提示词注入</li>
<li><strong>来源与时间</strong>：The Decoder · 1 天前</li>
</ul>
<h3 id="aisunohttpsthedecodercomgermancourtrulesaimusicgeneratorsunoviolatedcopyrightsrejectsfairusedefense"><a href="https://the-decoder.com/german-court-rules-ai-music-generator-suno-violated-copyrights-rejects-fair-use-defense/">德国法院判定 AI 音乐生成器 Suno 侵犯版权，驳回“合理使用”辩护</a></h3>
<p>德国慕尼黑一法院裁定，AI 音乐生成器 Suno 在训练和输出环节均构成版权侵权，并明确拒绝了德国的文本与数据挖掘例外条款及美国的合理使用抗辩。</p>
<ul>
<li><strong>要点</strong>：</li>
<li><strong>侵权证据</strong>：法院认定原告提供的 6 首歌曲在 Suno 的模型中存在“可复制性存储（reproducibly stored）”。</li>
<li><strong>行业震荡</strong>：该判决并非终局判决，但对整个生成式 AI 行业依靠公开版权数据进行训练的商业模式敲响了警钟。</li>
<li><strong>标签</strong>：#AI版权 #法律诉讼 #Suno #生成式AI</li>
